## Overview

This project focused on creating a simple multi-user app for a small graphic design studio in order to migrate an outdated paper-based managment system to a modern and efficient app. The app is divided into two parts:
- Front-end: a client app running locally on the different workers' PCs, with different interfaces based on admin/user;
– Back-end: a local server running 24/7 on a NAS which manages each client's requests and updates the SQL database.
