## Overview

The aim of this project was to build a small analytical framework for telling clearer stories with data. The emphasis was on clarity, usability, and making the important signals easy to interpret.

## Focus areas

- translating exploratory analysis into polished visual summaries
- designing interaction patterns that support fast decision-making
- combining narrative and quantitative evidence in the same flow

## Practical value

The result was a more disciplined way to communicate uncertainty, highlight key patterns, and keep the audience grounded in the actual evidence instead of noise.
