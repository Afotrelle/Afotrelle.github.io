## Overview

This project focused on creating small reusable tools for visual explanation: comparison views, pattern summaries, and interactive experiments to reason more effectively about model behavior.

## Why it matters

Scientific work often fails not because the method is wrong, but because the signal is hard to interpret. These tools were designed to make evaluation and communication more direct.

## Built around

- lightweight interactive exploration
- visual comparisons across models and runs
- concise summaries for collaborators and stakeholders
